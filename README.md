# DyeTool

**光化学染料光谱处理与单线态氧量子产率分析工具**

DyeTool 是一个面向光化学、光敏染料与光动力研究者的 Windows 桌面程序。它把紫外–可见
吸收光谱和荧光发射光谱的读取、质控、动力学拟合、Φ_Δ 计算、摩尔消光系数估算与论文级
出图连成一条完整流程，减少在 Excel、Origin 和脚本之间来回搬运数据的工作。

## 适用场景

- 以 ABDA 等探针测定单线态氧量子产率（Φ_Δ）。
- 比较不同染料、溶剂、气氛或光照条件下的光漂白/动力学速率。
- 由浓度序列估算摩尔消光系数 ε，或批量导出指定波长处的吸光度。
- 整理吸收/发射光谱，生成可直接用于论文或报告的 JACS 风格图件。
- 批量处理多个实验目录，并汇总历史 run 的 k_obs、Φ_Δ 与拟合质量。

## 主要功能

- **Φ_Δ 分析**：自动/手动分组、背景扣除、参比归一、误差传递、bootstrap 校验和对照判定。
- **k_obs 对比**：多组准一级速率常数对比，可指定参比组并换算 Φ_Δ。
- **作图工作台**：归一化叠图、吸收–发射镜像图、堆叠图、时间演化图、ε 表和 Stokes 位移。
- **论文风格出图**：JACS 单栏版式、>=600 dpi、自动图注；先低分辨率预览，再定稿出图。
- **光物理表征**：荧光量子产率相对法、亮度、光漂白单指数拟合与汇总表。
- **批量与档案**：多目录队列、历史 run 统计、Excel 多 sheet 汇总与多面板拼版。
- **输入只读**：程序不会修改、移动或重命名原始光谱文件。

## 系统要求

- Windows 10/11（64 位）
- 源码运行需要 Python 3.9 或更高版本
- 日常使用建议 1920×1080 或更高分辨率；程序也支持 1024×640 的最小窗口

## 获取与安装

### 方式一：使用打包版（推荐给普通用户）

下载并解压发行包后，双击 dye_tool.exe 即可运行，不需要安装 Python 或配置环境。

如果仓库暂时没有提供发行包，可以按下面的源码方式运行，或使用 packaging/build.ps1 自行构建。

### 方式二：从源码运行

~~~powershell
git clone https://github.com/qwt-pamg/dye-cache.git
cd dye-cache/dye_tool
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe app.py
~~~

首次运行前请确认依赖安装完成；Windows 上如果 PowerShell 禁止执行脚本，可直接用上面的
python.exe 命令，不需要修改执行策略。

## 第一次分析

1. 打开 **① 数据**，选择包含光谱文件的目录。
2. 在文件表中确认组别、角色和时间；命名不规范时可直接在工作表里修改。
3. 打开 **② 分析**，选择 Φ_Δ 任务，按需调整探针波长、参比 Φ_ref 等参数。
4. 点击**开始分析**，先查看低分辨率预览图。
5. 确认无误后点击**定稿出图**，生成 600 dpi 图件与图注。
6. 在 **④ 档案** 中查看历史 run、统计报表或导出汇总。

## 数据准备

### 支持的文件格式

| 类型 | 来源/格式 | 说明 |
|---|---|---|
| 紫外–可见吸收 | 两列 波长,吸光度 文本/CSV | 自动识别编码，空值按 NaN 处理 |
| 荧光发射（文本） | 仪器导出的两列文本 | 自动读取激发/发射波长范围 |
| 荧光发射（二进制） | .fds 二进制存档 | 读取原始精度数据 |
| 紫外–可见（二进制） | .spc 二进制存档 | 支持多数据集存档 |

文件类型按内容识别，不依赖扩展名；文本、二进制格式可混放在同一目录。

### 文件命名（可选）

命名规范可以让程序自动读取时间，减少手工整定：

~~~text
组名[_重复号]-秒数[+分钟数].txt
~~~

示例：

- sample-90.txt：t = 90 s
- sample-90+5.txt：t = 390 s
- ref-60.txt：参比组，t = 60 s
- bg-0.txt：背景组，t = 0 s
- dark-120.txt / n2-60.txt / nan3-60.txt：对照实验

命名不是强制要求；不符合约定时，在 ① 数据页的时间工作表中直接修改即可。

## 输出文件

每次分析会在 runs/<染料>/<时间戳>/ 下生成：

- results.csv：逐组结果与拟合参数
- fit_summary.json：拟合摘要
- report.md：中文分析报告
- run.log：运行日志
- figures/：PNG/SVG 图件与 captions.md 图注
- 按需生成 Excel 汇总或队列汇总表

原始数据目录不会被写入；需要保留原始文件时无需额外备份设置。

## 命令行（可选）

GUI 与命令行共用同一套计算核心，便于批处理或脚本调用：

~~~powershell
./.venv/Scripts/python.exe -m core.cli --self-test
./.venv/Scripts/python.exe -m core.cli <数据目录>
./.venv/Scripts/python.exe -m core.cli <数据目录> --dry-run
./.venv/Scripts/python.exe -m core.cli --help
~~~

## 常见问题

**为什么按钮是灰色的？**
把鼠标停在按钮上，会显示当前不可用的具体原因，例如尚未选择数据目录、没有可解析的
光谱，或已有任务在运行。

**载入后出现“剔除”标记怎么办？**
文件表会给出中文原因（空文件、点数不足、波长轴异常等）。原始文件不会被删除或修改；
修正文件后重新载入即可。

**图件分辨率是多少？**
定稿图默认 600 dpi，按 JACS 单栏 82.5 mm 版式输出；预览图分辨率较低，仅用于快速检查。

**可以只用命令行吗？**
可以。核心计算层不依赖 GUI，详见 core/cli.py 的 --help。

## 已知限制

- 加密的 Excel 工作簿不参与自动读取。
- 仅支持文档中列出的光谱格式；其他仪器格式需要先导出为文本/CSV。
- FDS 目前只支持荧光发射谱，吸收/PMT/EEM 变体尚未覆盖。
