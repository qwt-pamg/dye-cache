# L17（评审记录）：免安装 exe 的"属性 → 详细信息"里原先**什么都没有**
# （没有产品名、没有版本号），用户右键看属性时无法确认拿到的是哪一版。
#
# 这个文件是 PyInstaller 的 `version=` 资源模板（VS_VERSIONINFO 的文本形式），
# 由 `packaging/build.ps1` 在打包前**按 core/__init__.py 的 VERSION 自动改写**
# 里面的版本字段，所以版本号只有一处真相（`core.VERSION`），不会两边漂移。
#
# 用法（spec 里）：
#     exe = EXE(..., version=str(SPECPATH / "version_info.txt"))
#
# 注意：`StringFileInfo` 里的键是**固定英文名**（ProductName 等），不能翻译；
# 值里的中文按 VS_VERSIONINFO 的约定走 UTF-16，PyInstaller 会自己处理编码。
